# Claude website usage (Free and paid)

1. In the tracker, add a Claude account or open its Details. Choose **Connect Claude website · Free & paid**.
2. Choose **Open companion folder**. In Chrome or Edge, open Extensions / Manage extensions, enable Developer mode, choose Load unpacked, and select the folder that just opened. This is a one-time local installation; the extension is not yet published in the stores.
3. In the tracker choose **Create connection code** and copy the code. It is valid for initial pairing for ten minutes. Do not share it.
4. Open **AI Usage Tracker — Claude companion** from the browser's Extensions menu. Paste the code and choose **Connect & open Claude**.
5. Sign in normally on claude.ai. Use the account you intend to track. Keep a Claude tab open and use Claude normally; Free readings may appear only after the next normal response. No test message is sent automatically.

The tracker shows reported **% remaining** and reset time. A last-observed timestamp identifies saved readings. Closing the browser pauses observations. Expired windows become unavailable; they are never guessed to be full. Click the companion icon to see connection status. The desktop app must be running to receive updates. Reopen a Claude tab after installing or updating the extension.

If you change Claude accounts/organizations, create a new connection code for the intended tracker card. Reconnecting clears previous imported history and usage to avoid mixing accounts. One browser companion instance pairs with one tracker card at a time. For multiple accounts, use separate browser profiles. Disconnecting the companion stops updates; **Unlink from tracker** also revokes its local key. Neither operation signs you out of claude.ai.

Only numeric usage windows and an organization identifier are sent to the local app. Chat text, cookies, login tokens, and passwords are not sent. The companion does not create messages. It reads unofficial website data, so Claude changes may require a companion update. A successful fixture test does not establish that every Free account currently exposes these fields; missing readings remain unavailable.

Claude Code sign-in and local token/activity history remain optional and separate. Website percentages are not converted into tokens, credits, or an estimated number of messages.
